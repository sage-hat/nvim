## 1. Про версии
Для работы конфига требуется JDK 21 и выше

**Проверка:**
```bash
java -version
```

---

## Установка Neovim
Нужна версия не ниже 0.8.x

```bash
# Если старая версия — используй AppImage
cd /tmp
wget https://github.com/neovim/neovim/releases/download/v0.10.3/nvim-linux-x86_64.appimage
chmod +x nvim-linux-x86_64.appimage
sudo mv nvim-linux-x86_64.appimage /usr/local/bin/nvim

# добавить алиас в .bachrc
alias nvim="/home/web-admin/.local/bin/nvim"

# Проверь версию
nvim --version
```


---

## Скачивание Java Language Server (jdtls)

```bash
mkdir -p ~/.local/share/nvim/jdtls
cd ~/.local/share/nvim/jdtls

# Скачиваем последнюю версию
wget https://download.eclipse.org/jdtls/snapshots/jdt-language-server-latest.tar.gz

# Распаковываем
tar -xzf jdt-language-server-latest.tar.gz

# Удаляем архив
rm jdt-language-server-latest.tar.gz

# Проверяем структуру
ls -la
# Должно быть: bin/  config_linux/  features/  plugins/
```

## Что работает после установки

| Функция                   | Клавиша          | Описание                                                              |
| ------------------------- | ---------------- | --------------------------------------------------------------------- |
| Открыть файловый менеджер | `Ctrl+E`         | Дерево папок слева                                                    |
| Закрыть файловый менеджер | `Ctrl+W+Q` или q |                                                                       |
| Найти файл                | `Ctrl+P`         | Быстрый поиск по имени<br>                                            |
| Найти по содержимому      | `Ctrl+F`         | Grep по проекту<br>`sudo apt-get install ripgrep`<br>Если не работает |
| Документация              | `K`              | Описание метода                                                       |
| Переход к определению     | `gd`             | Перейти к объявлению                                                  |
| Найти ссылки              | `gr`             | Где используется                                                      |
| Переименовать             | `rn`             | Переименовать во всем проекте                                         |
| Следующая ошибка          | `]d`             | Перейти к следующей ошибке                                            |
| Предыдущая ошибка         | `[d`             | Перейти к предыдущей ошибке                                           |

# Инструкция по работе с файловым менеджером (nvim-tree)

## Открытие и закрытие

| Действие                                    | Клавиша  |
| ------------------------------------------- | -------- |
| Открыть дерево                              | `Ctrl+E` |
| Закрыть дерево                              | q        |
| Обновить дерево (если добавили файлы извне) | `Ctrl+R` |

---

## Навигация по дереву

| Действие                          | Клавиша             |
| --------------------------------- | ------------------- |
| Перемещение вверх/вниз            | `j` / `k`           |
| Раскрыть каталог                  | `Enter` или `l`     |
| Закрыть каталог                   | `Backspace` или `h` |
| Сделать каталог корневым          | C + ]               |
| Перейти в корневую папку (проект) | `~`                 |
| Скрытые файлы и каталоги          | `H`                 |
| Перейти в родительскую папку      | `-` (минус)         |


---

## Работа с файлами и папками

| Действие           | Клавиша   | Описание                                         |
| ------------------ | --------- | ------------------------------------------------ |
| **Создать файл**   | `a`       | Создает новый файл в текущем каталоге. В         |
| **Создать катаог** | `a` + `/` | Введи имя с `/` на конце, например `src/`        |
| **Удалить**        | `d`       | Удаляет файл или каатлог (с подтверждением)      |
| **Переименовать**  | `r`       | Переименовывает файл или катлог                  |
| **Копировать**     | `c`       | Копирует файл/каталог в буфер                    |
| **Вырезать**       | `x`       | Вырезает файл/каталог в буфер                    |
| **Вставить**       | `p`       | Вставляет файл/каталог из буфера в текущую папку |
| **Дублировать**    | `y`       | Дублирует файл (создает копию)                   |

---

## Открытие файлов

| Действие | Клавиша |
|----------|---------|
| Открыть файл (в текущем окне) | `Enter` |
| Открыть файл (в новом вертикальном сплите) | `s` |
| Открыть файл (в новом горизонтальном сплите) | `i` |
| Открыть файл (в новой вкладке) | `t` |
| Просмотр файла (без редактирования) | `o` |

---

## Управление деревом

| Действие | Клавиша |
|----------|---------|
| Обновить дерево | `R` |
| Скрыть/показать скрытые файлы | `g + d` |
| Скрыть/показать файлы в `.gitignore` | `g + i` |
| Закрыть дерево | `Ctrl+E` (еще раз) |

---

## Поиск в дереве

| Действие | Клавиша |
|----------|---------|
| Найти файл по имени (в дереве) | `/` (в режиме нормального просмотра дерева) |
| Следующее совпадение | `n` |
| Предыдущее совпадение | `N` |
